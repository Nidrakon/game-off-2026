# Time Shifter

Entry for [GitHub Game Off 2026](https://itch.io/jam/game-off-2026) by [Nidrakon](https://nidrakon.itch.io).

A humorous 2D puzzle platformer: a scatterbrained professor uses his Time Shifter, a device that slows down or speeds up time in a bubble around him, to escape his own trap-filled underground lab. His pizza is waiting upstairs.

- **Theme:** SHIFT
- **Engine:** Godot 4
- **Platforms:** Browser, Windows
